# Common Mistakes to Avoid

1. **Passing Non-ISO Dates to Transactions**:
   - *Mistake*: Setting `valueDate: "02/12/24"` or `"02-Dec-2024"`.
   - *Why it breaks*: `validateTransaction` uses `isISODate(/^\d{4}-\d{2}-\d{2}$/)`. Non-ISO dates fail validation, causing `compute()` to discard the transaction, resulting in empty tables.
   - *Correct*: Always normalize to ISO format (`2024-12-02`) in state; format for display only inside templates.

2. **Editing Bundled CLI Files Directly**:
   - *Mistake*: Editing `scripts/render_cli.mjs` directly.
   - *Why it breaks*: `render_cli.mjs` is generated by esbuild from `scripts/render_cli.jsx`. Any changes made directly to `.mjs` get overwritten the next time esbuild runs.
   - *Correct*: Always edit `scripts/render_cli.jsx` and re-bundle.

3. **Using Hardcoded Absolute Paths in Scripts**:
   - *Mistake*: `import StatementDocument from '/home/sugat/Downloads/viraj kadam/...'`.
   - *Why it breaks*: Breaks whenever cloned on another machine or path.
   - *Correct*: Always use relative imports (`../app/pdf/StatementDocument.jsx`).
